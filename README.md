# DISC Test - Sistem Pakar Kepribadian

Aplikasi web tes kepribadian DISC berbasis **sistem pakar** (Forward Chaining & Certainty Factor). 

## Fitur

- Tes DISC dengan hasil dan profil kepribadian
- Undangan tes untuk kelompok lewat tautan, kode QR, atau WhatsApp
- Dapat dibuka dari HP maupun komputer

## Menjalankan Secara Lokal

1. Unduh file `DISC_Test_Lengkap.html` (klik tombol **Download raw file** di GitHub, atau clone repository ini).
2. Buka file tersebut di browser (klik dua kali).

> Aplikasi memuat font (Google Fonts) dan pustaka kode QR dari internet, jadi sambungkan perangkat ke internet agar tampilan dan fitur QR berfungsi penuh.
